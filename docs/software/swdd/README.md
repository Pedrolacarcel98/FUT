# SWDD — instancia de este proyecto

Las **convenciones del método** para este nivel están en `_convenciones.md`, que se
materializa desde el submódulo del sistema y **no se edita a mano**: los cambios van al
sistema, para que todos los proyectos los reciban.

Este fichero es para lo que **solo aplica a este proyecto**.

> Los agentes leen **los dos**: `_convenciones.md` para el *cómo*, y este `README.md`
> para la *instancia*. Si se contradicen manda este fichero —es una decisión explícita
> del proyecto— pero el agente debe señalarlo.
